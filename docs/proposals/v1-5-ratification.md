Use the actual controlling full/interim Council, not proposed seats. R14 constitutional/Succession/Office powers require their own explicit adoption; a three-yes R15-M vote does not enact R14-C or sanctions. If the valid old Council is nonfunctional, actual Owner interim instrument/elections must precede target adoption as described in R14. No quorum or ratification means blocked amendment. Record exact revision, consultation normally 48 hours, conflicts, actual seats, named votes, Owner signature where reserved, effective scope/date, owner and review date. No fictitious approval record.

## Migration

Inventory actual work/accepted capacity, qualifications, earned standing, managers, cases and access privately. Consult Heads/Leads/contributors; publish scoped routine functions and select qualified willing owners using relevant samples. Keep current managers unless an actual fair reassignment is agreed; no silent demotion, mandatory hours or automatic functional-grade promotion. Remove displaced delivery from accepted rosters BEFORE adding functional or case work. Review coaching load before creating any additional People Lead.

Register category-specific reserve candidates in stages, then assess and obtain actual authorizations/consent. Preserve senior initial judges separately. Screen current reporting/prior cases; no operational Head controls protected findings. Recheck continuing cases and access, revoke old scope where superseded and give actual contacts safe notice. After lawful adoption, one recorded effective update replaces superseded assignment practices; do not run competing control chains. Test coverage, private storage, expiry/revocation and handover before promising independent case service. Review at 30/90 days through existing exceptions; correct poor assignments through valid authority.
